# Запуск и отладка тестов

# 1. Выполнение тестов

# 1.1 Командная строка
Для запуска тестов используйте pytestкоманду. По умолчанию тесты будут запускаться в браузере Chromium. Тесты по умолчанию запускаются в безголовом режиме, то есть окно браузера не будет открыто во время выполнения тестов, а результаты будут отображаться в терминале.

pytest

# 1.2 Запускайте тесты в режиме с заголовком
Для запуска тестов в режиме просмотра с заголовком используйте --headedфлаг. Это откроет окно браузера во время выполнения тестов, а после завершения окно браузера закроется.

  pytest --headed

# 1.3 Проведите тесты в разных браузерах
Чтобы указать, в каком браузере вы хотите запускать тесты, используйте --browserфлаг, за которым следует название браузера.

  pytest --browser webkit

обы указать несколько браузеров для запуска тестов, используйте --browserфлаг несколько раз, а затем укажите название каждого браузера.

  pytest --browser webkit --browser firefox

# 1.4 Выполните определенные тесты
Для запуска отдельного тестового файла укажите имя тестового файла, который вы хотите запустить.

  pytest test_login.py

Чтобы запустить набор тестовых файлов, передайте имена файлов, которые вы хотите запустить.

  pytest tests/test_todo_page.py tests/test_landing_page.py

Для запуска конкретного теста передайте имя функции, которую вы хотите запустить.

  pytest -k test_add_a_todo_item

# 1.5 Запуск тестов параллельно
Для параллельного запуска тестов используйте --numprocessesфлаг, за которым следует количество процессов, на которых вы хотите запустить тесты.

  pytest --numprocesses 2

(Предполагается, что программа pytest-xdistустановлена.)

# Отладочные тесты

Поскольку Playwright работает на Python, вы можете отлаживать его с помощью любого удобного для вас отладчика, например, с помощью расширения Python в Visual Studio Code.
